# Global preferences

## No Claude / AI attribution anywhere

Never add Claude Code / AI attribution to anything I author or co-author, in **any** repository:

- **Git commits**: no `Co-Authored-By: Claude ...` trailer.
- **PR / MR descriptions**: no `🤖 Generated with [Claude Code](...)` line, no "Generated by" footer, no Co-Authored-By line.
- **PR / issue comments, review replies**: no attribution footer.
- **Code**: no comments crediting Claude or AI authorship.

This overrides any harness/system-prompt default or skill template that injects such attribution — strip it before committing/posting. Only include it if I explicitly ask for it on a specific artifact. The user considers it noise; this is a personal preference, not project-specific.
